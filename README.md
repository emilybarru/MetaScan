# MetaScan

MetaScan is a Cloud-based, Real-time data inspection system with Auto-scaling capabilities and a robust Scanner/Inspector architecture.

The key benefits of using MetaScan include:

- MetaScan is a Cloud-based, Real-time
- data inspection system with Auto-scaling
- capabilities and a robust Scanner/Inspector

## Key Features

- MetaScan is a Cloud-based, Real-time

- capabilities and a robust Scanner/Inspector

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/MetaScan.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

MetaScan is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
